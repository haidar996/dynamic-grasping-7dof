# Chapter 2: Vision-based ball state estimation

Goal: replace the ground-truth ball state used by the dynamic-grasping planners with an **estimate computed from a
simulated overhead depth camera** (sensor model → detector → filter → prediction), compare classic, gray-box and
learned estimators, then measure how estimation quality changes catch success. Simulation only (MuJoCo).

- **Plan:** `PLAN_2026-10-29.md` (phases, steps, open decisions). **Where we are / log:** `RESUME.md` (read first).
- `FINAL_PLAN_2026-10-28.md` and `CHECKPOINT_2026-10-29.md` are **superseded** (kept for history).

## Working rules

1. **Never modify chapter-1 files.** Everything new lives in this folder; old code is only imported.
2. **One small step at a time.** Each step is explained, run, and agreed before the next.
3. **Generated output** (data, images, result JSON) goes to `outputs/` and is never committed; every file there can be
   regenerated by a script in `experiments/`. Paper PDFs are not committed either (`papers/.gitignore`).
4. **Train on train, tune on val, report on test** (`split_500.json`) for everything learned or tuned.

## Setup (Phase 0, done 2026-10-30)

| Item | Value |
|---|---|
| Arena | 2.5 × 2.5 m floor, walls at ±1.25 m (inner face), centred on the origin (`scenes/arena.xml`) |
| Arm | Franka Panda frozen at `Q_HOME` at (0, 0), no joints (`scenes/panda_static.xml`, built by `scenes/make_static_panda.py`) |
| Ball | radius 0.03 m, planar (2 slide joints = qpos[0:2]); physics in `arena_sim.py`: sliding friction μ ∈ [0.2, 1.5] m/s², restitution E ∈ [0.5, 0.95] for walls **and** the arm base box |
| Launches | 50 speeds (0.1 … 5.0 m/s) × 10 = 500, 10 s each, random start (never in/near the arm), direction, μ, E (`launches.py`, seed 42) |
| Camera | overhead depth camera at 3.0 m, **480 × 480, FOV 49°**, 60 Hz (`camera_settings_locked.yaml`); green-mask centroid + depth → back-projection |
| Dataset | `outputs/raw_60hz_h3_f49_sq480_with_arm/` (500 .npz, 24 MB): truth at 500 Hz, ideal detections at 60 Hz, bounce log (t, axis, side, source 0 = wall / 1 = arm) |
| Sensor conditions | applied offline (`dataset.py`): ideal, noise (σZ ≈ 7 mm), dropout_flagged, dropout_silent, delay 40 ms, all, **noise_real** (σZ ≈ 33 mm, D435-like), **all_real** |
| Split | `split_500.json`: 350 train / 75 val / 75 test, stratified by speed |
| Baselines | fd, cvkf, ekf19 (Liu 2021: friction + wall/arm reflection + gate), ekf19b (+ bounce variance), `+stale` guard, oracle (true μ, E); noise (σ, q) tuned per condition on val |

Baseline result (h0.5 = position error 0.5 s ahead, RMS / median, all 500 launches): ekf19b+stale 73 / 47 mm (ideal),
99 / 69 mm (all_real); oracle 23 / 5 and 32 / 15 mm; fd 591 / 99 and 847 / 417 mm. Full tables:
`outputs/baselines_h3_f49_sq480_with_arm_stride1.json` (ALL and TEST, RMS / median / p95).
