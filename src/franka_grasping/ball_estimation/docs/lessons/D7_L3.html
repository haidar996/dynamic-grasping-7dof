السياسات في filters.py

جواب سؤال D7 L1: إذا خفضنا k_reset = 2 بدلاً من 3:

  • الإيجابي: نعيد ضبط أسرع إذا كانت الكاميرا متجمدة (نتعافى بسرعة)
  • السلبي: قياسان سيئان متتاليان يسبب reset (قد يحدث بالصدفة)، نفقد التعلم بسرعة أكبر
  • الحل الوسط: 3 أفضل—يسمح بـ glitch واحد أو اثنين بدون reset فوري

1. الملف والمعاملات

السياسات في estimators/filters.py، فئة EKF19:

def __init__(self, c=0.85, E=0.725, L=0.97, q=0.5, sigma=0.005,
             gate_p=0.99, policy="hybrid", k_reset=3, ...):
    self.policy = policy          # "none" | "skip" | "reset" | "hybrid"
    self.k_reset = k_reset        # عدد الرفضات قبل reset
    self.gate = chi2.ppf(gate_p, 2)  # عتبة chi-square

policy افتراضي "hybrid"، k_reset افتراضي 3.

2. مراحل المرشح في update()

def update(self, t, xy, valid):
    if not valid:
        return  # لا قياس، لا شيء

    z = np.asarray(xy, float)

    if not self.ready:
        # أول قياس: ابدأ من هنا
        self.s = np.array([z[0], z[1], 0.0, 0.0])
        self.P = self.P0.copy()
        self.t, self.ready = t, True
        return

    if t > self.t:
        self._predict(t - self.t)  # تنبؤ

    self.t = t

    # ============ الـ Gate والسياسات ============
    y = z - self.s[:2]  # التنبية
    S = self.P[:2, :2] + self.R * np.eye(2)

    # فحص الـ Gate
    if self.policy != "none" and y @ np.linalg.solve(S, y) > self.gate:
        # قياس مريب!
        self.n_gate += 1
        self.fails += 1  # زد عداد الرفضات

        if self.policy == "reset":
            # reset فوراً
            self._reset_to(t, z)
        elif self.policy == "hybrid" and self.fails >= self.k_reset:
            # انتظر k_reset رفضات، ثم reset
            self._reset_to(t, z)
        # else: policy == "skip" أو hybrid لكن fails < k_reset
        # تجاهل القياس، لا تحديث
        return

    # قياس جيد—تحديث عادي
    self.fails = 0  # أعد عداد الرفضات
    K = self.P[:, :2] @ np.linalg.inv(S)
    self.s = self.s + K @ y
    self.P = (np.eye(4) - K @ np.eye(4)[:2]) @ self.P

3. دالة _reset_to

def _reset_to(self, t, z):
    self.s = np.array([z[0], z[1], 0.0, 0.0])  # موقع من القياس، سرعة صفر
    self.P = np.eye(4)  # تباين أولي (الورقة: identity)
    self.t, self.fails = t, 0
    self.n_reset += 1  # عداد كم مرة reset

لاحظ:

  • الموقع من z (القياس الجديد)
  • السرعة 0, 0 (افتراض)
  • التباين identity (عدم يقين عالي)
  • self.n_reset يتتبع عدد resets (للإحصائيات)

4. مثال: كود ينشئ مرشحات بسياسات مختلفة

from estimators.filters import make

# Kalman خطي (بدون احتكاك، بدون gate)
cvkf = make("cvkf")  # c=0, policy="none"

# EKF مع احتكاك، بدون gate
ekf19_none = make("ekf19-none")  # policy="none"

# EKF مع احتكاك، skip على قياسات سيئة
ekf19_skip = make("ekf19-skip")  # policy="skip"

# EKF مع احتكاك، hybrid (افتراضي)
ekf19_hybrid = make("ekf19-hybrid")  # policy="hybrid", k_reset=3

# EKF مع احتكاك + تصحيح bounce، hybrid
ekf19b_hybrid = make("ekf19b-hybrid")  # sigma_E=0.13, policy="hybrid"

# مخصص: hybrid مع k_reset=5
ekf19b_custom = make("ekf19b-hybrid", k_reset=5)

5. التتبع والإحصائيات

المرشح يحسب عدادات:

  • self.n_gate: كم مرة رفع الـ Gate قياس
  • self.n_reset: كم مرة reset المرشح
  • self.fails: عداد رفضات متتالية حالي (يُعاد للصفر عند قياس جيد)

في النتائج النهائية، نتفقد: "في 500 launch، الـ gate رفع 35 مرة، reset 8 مرات".

6. الخلط: policy مع sigma_E

لا تخلط! هذان مستقلان:

  • sigma_E = تصحيح bounce (يضيف تأكد في السرعة قبل الارتداد المتوقع)
  • policy = ماذا تفعل عند قياس سيء (skip/reset/hybrid)

يمكنك استخدام sigma_E=0.13, policy="hybrid" معاً:

  • sigma_E يُقلل المفاجأة من الارتداد
  • policy يتعامل مع قياسات سيئة أخرى (تجمد، ضجيج)

سؤال للتأكد

في دالة _reset_to، لماذا السرعة نُفترض صفر ([0, 0]) بدلاً من محاولة تخمين السرعة من القياس السابق؟
