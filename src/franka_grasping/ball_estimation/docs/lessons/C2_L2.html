الدرس C2 · الطبقة 2: التعريفات الدقيقة

الـ quantiser، وخطأ التكميم، واشتقاقه

جواب سؤال التوضيح السابق: عند Z = 1 m: خطوة العمق 12 × 0.125 / 31.18 = 4.0 mm. وإذا اقترب الجسم 1 سم (من 1.00 إلى 0.99 م) فالإزاحة d = fB/Z تتغير من 31.18 إلى 31.49، أي 0.315 px، وهذا نحو 2.5 خطوة (الخطوة 0.125). إذن يحس الحساس بحركة 1 سم عند 1 م بسهولة، ويحس حتى بحركة 4 مم (خطوة واحدة).

1. التعريفات

  • الإزاحة الحقيقية d = fB / Z (بكسل).
  • المُكمِّم (quantiser) بخطوة Δ: Q(d) = Δ · round(d / Δ). يقرّب إلى أقرب مضاعف للخطوة.
  • العمق المقيس Ẑ = fB / Q(d).
  • خطأ الإزاحة ε = Q(d) − d، وهو بين −Δ/2 و+Δ/2.

في الكود (Sensor.corrupt_depth):

fB = self.cam.f * p.baseline
z = fB / (np.round(fB / z / p.quant_step) * p.quant_step)

السطر الثاني هو بالضبط Ẑ = fB / ( round(d/Δ) · Δ ) مع d = fB/z.

2. الاشتقاق: خطأ العمق بدلالة خطأ الإزاحة

نحسب الخطأ بدقة: Ẑ − Z = fB/(d + ε) − fB/d = − fB ε / ( d (d + ε) ).

الخطأ ε (أقل من 0.0625 بكسل) صغير جداً مقابل d (حوالي 10)، فنهمله في المقام: d + ε ≈ d. ثم d = fB/Z فإن fB / d2 = Z2/(fB):

Ẑ − Z ≈ − ( Z2 / f B ) · ε

الخطأ في العمق هو الخطأ في الإزاحة مضروباً في Z2/(fB) (وهذا ما قلناه عن شكل المنحنى).

3. توزيع الخطأ

إذا كانت الإزاحة الحقيقية «عشوائية بما يكفي» فإن ε منتظم على [−Δ/2, Δ/2] بانحراف معياري Δ/√12 (من A5). إذن:

σquant = ( Z2 / f B ) · Δ / √12

عند 3 م: 9 × 0.125 / 31.18 / 3.46 = 10.4 mm.

4. فحص بأرقام ومحاكاة

  • حالة واحدة: Z = 3.000 يعطي d = 10.3923. أقرب علامة 10.375 (أي ε = −0.0173). فالعمق المقيس 31.1769/10.375 = 3.00500، أي خطأ +5.00 mm. والاشتقاق يعطي −(9/31.18) × (−0.0173) = +4.99 mm: مطابق.
  • محاكاة: 40000 عمقاً عشوائياً بين 2.95 و3.05 م وُضعت في corrupt_depth الحقيقية: الانحراف المعياري 10.18 mm مقابل 10.42 المتوقع. اتفاق جيد (الفرق من أن النطاق صغير فلا يغطي كل المراحل بالتساوي).
  • مع noise العمق قبله: الدالة تضيف الـ noise أولاً ثم تكمّم. الانحراف الكلي 12.5 mm، وجمع التباينين √(7.382 + 10.42) = 12.8: قريب.

5. حدود الاشتقاق

  • افترضنا ε منتظماً: صحيح إذا تغيّر العمق عبر عدة خطوات. لكرة ساكنة العمق ثابت، فالخطأ ثابت (ليس عشوائياً).
  • أهملنا ε في المقام: خطأ نسبي 0.5% فقط.
  • الخطوة Δ = 0.125 (1/8 بكسل) من Kinect. حساسات أخرى لها خطوات مختلفة.

سؤال للتأكد (احسب بنفسك)

Z = 2 m: احسب d = fB/Z وأقرب علامة (خطوة 0.125) والعمق المقيس والخطأ بالمليمتر. ثم قارنه بالصيغة (Z2/fB) × (−ε).
