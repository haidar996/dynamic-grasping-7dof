الدرس C4 · الطبقة 2: التعريفات الدقيقة

سلسلة ماركوف: معدل الضياع ومتوسط الفجوة

جواب السؤال السابق: 3 × 0.1 = 0.30 m. وفي الوضع الصامت يظن الـ estimator أن الكرة بقيت في مكانها (لأن القياس المتكرر يقول ذلك).

1. التعريف

في كل إطار الحالة إما S (مرئي، seen) أو L (ضائع، lost). الحالة القادمة تعتمد على الحالة الحالية فقط (خاصية ماركوف: لا ذاكرة لأبعد من ذلك). الانتقالات:

from \ toSL
S1 − pp
Lq1 − q

حيث p = P(S → L) احتمال بدء الضياع، وq = P(L → S) احتمال انتهائه.

2. متوسط طول الفجوة

إذا كنا في L فالفجوة تستمر كل إطار باحتمال 1 − q. إذن طول الفجوة n (بالإطارات) له التوزيع الهندسي:

P(n) = (1 − q)n−1 q,    mean = 1 / q

فمتوسط الفجوة g = 1/q، أي q = 1/g. بالمثل متوسط فترة الرؤية المتواصلة 1/p.

3. معدل الضياع على المدى الطويل

نسبة الإطارات الضائعة (التوزيع المستقر): نحلّ πS p = πL q (التدفق من S إلى L يساوي العكس) مع πS + πL = 1:

πL = r = p / (p + q)  ⇒  p = r q / (1 − r)

وهذه هي المعادلة في الكود:

q  = 1.0 / g                    # P(lost -> seen)
pl = r * q / (1.0 - r)          # P(seen -> lost), gives long-run loss rate r
if self.lost:   self.lost = not (self.rng_loss.random() < q)
else:           self.lost = self.rng_loss.random() < pl

4. أرقامنا

r = 0.05، g = 6: q = 1/6 = 0.1667، p = 0.05 × 0.1667/0.95 = 0.00877. فمتوسط الرؤية المتواصلة 1/p = 114 إطاراً (1.9 ث) ومتوسط الفجوة 6 إطارات.
