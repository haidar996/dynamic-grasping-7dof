العالم مقابل نموذج الـ estimator

جواب السؤال السابق: v′ = (−1.5, 4)، سرعتها √(2.25 + 16) = 4.27، وtan φout = 4/1.5 = 2.67.

1. نسختان من نفس الفيزياء

في مشروعنا فيزياء الكرة مكتوبة مرتين، في مكانين مختلفين ولغرضين مختلفين:

  • العالم arena_sim.py (Arena.step): هو الحقيقة. يستعمل μ وE الحقيقيين لكل إطلاق، وخطوة 2 ms، ويستعمل MuJoCo للتكامل.
  • نموذج الـ estimator estimators/model.py (propagate): هو ما يعتقده الـ estimator. يستعمل c, E (تقريبيين، أو الحقيقيين للـ oracle)، وخطوة حتى 10 ms، وهو Python خالص بلا MuJoCo.

2. الكودان

العالم (مختصر):

force = -mass * mu * v / |v|          # friction, from v at the START of the step
mj_step(...)                         # semi-implicit Euler, h = 0.002
if p > limit and v > 0:            # wall
    p = limit; v = -e * v            # clamp, discard the overshoot

النموذج (propagate):

sp = hypot(vx, vy)
if c*h >= sp: vx = vy = 0.0         # friction would stop the ball inside this sub-step
else:  f = c*h/sp; vx -= f*vx; vy -= f*vy
x += vx*h; y += vy*h                 # move with the new velocity
if x > L:  x = L - E*(x - L); vx = -E*vx   # mirror the overshoot

4. قياس: كم يبعد النموذج عن العالم لو كان كل شيء معروفاً؟

النتيجة: الفرق بين النموذج والعالم صغير: حوالي 2 مم عند ثانية. وخطأ الـ oracle في نتائجنا 17.8 مم عند ثانية. إذن معظم خطأ الـ oracle ليس من اختلاف النسختين، بل من خطأ تقدير الحالة نفسها (المكان والسرعة من الكاميرا). وبذلك ضعفت الشكوك التي طرحتها في A2 (الخطوة 10 ms، واختلاف الارتداد): تأثيرها موجود لكنه صغير.
