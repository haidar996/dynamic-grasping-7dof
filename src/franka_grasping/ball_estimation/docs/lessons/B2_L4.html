من المشهد إلى (u, v, z)

جواب السؤال السابق: البكسل 2/415.7 = 4.81 mm، وخطأ التقريب 4.81/√12 = 1.39 mm. الكاميرا الأقرب أدق.

1. render: صورتان في كل إطار

def render(self, data):
    self.renderer.disable_depth_rendering()
    self.renderer.update_scene(data, camera=self.name)
    rgb = self.renderer.render().astype(int)      # colour image
    self.renderer.enable_depth_rendering()
    self.renderer.update_scene(data, camera=self.name)
    depth = self.renderer.render().copy()         # depth image (metres, float32)
    return rgb, depth
  • update_scene يجعل الرسّام يقرأ حالة المحاكي الحالية (data) ومن منظور كاميرتنا overhead.
  • ثم رسمتان: واحدة للون وواحدة للعمق. لذلك الإطار الواحد يكلّف حوالي 16 ms، و300,000 إطار (500 إطلاق) أخذت 77.7 دقيقة.
  • .astype(int) مهمة: الصورة تأتي أعداداً صحيحة بحجم 8 بت (0 إلى 255). لو كتبنا R + 40 على هذا النوع لانقلب الرقم عند 255. جرّبتُ: 250 + 40 بنوع 8 بت يعطي 34 لا 290. فنحوّل إلى أعداد أكبر قبل المقارنة في القناع.
  • .copy() لأن المصفوفة التي يعيدها الرسّام تُعاد كتابتها في الرسم التالي، فننسخها.

2. measure_parts: خطوة الكشف

def measure_parts(self, data):
    rgb, depth = self.render(data)
    uv = self.detect(rgb)                  # mask + centroid (B2 L2)
    if uv is None:
        return None                        # ball not seen
    return uv[0], uv[1], depth[int(round(uv[1])), int(round(uv[0]))]
  • ترجع ثلاثة أعداد (u, v, z) أو None إذا لم تُرَ الكرة.
  • القراءة depth[int(round(v)), int(round(u))]: الصف أولاً ثم العمود.
  • تفصيلة: دالة round في Python تقرّب النصف إلى أقرب عدد زوجي: round(197.5) = 198 وround(2.5) = 2 وround(3.5) = 4. لا أثر عملي هنا (فرق بكسل واحد في قراءة العمق)، لكنه يفاجئ.

3. لماذا نحفظ (u, v, z) ولا نحفظ (x, y)؟

measure تضيف الخطوة الأخيرة: back_project(*parts). لكن في توليد البيانات (دورة 77.7 دقيقة) حفظنا (u, v, z) المثالية بلا noise في الملفات. ثم نضيف الـ noise (jitter على u, v، وخطأ العمق على z) لاحقاً، وفي كل مرة نشاء، ثم نحوّل إلى (x, y). لو حفظنا (x, y) لما استطعنا إضافة noise العمق بشكله الصحيح (يتناسب مع Z2) على الأرقام الخام.

سؤال للتأكد

ماذا يحدث لو أزلنا .astype(int) من render؟ أعطِ مثالاً بلون بكسل أخضر ساطع (R=0, G=250, B=0) وبلون بكسل أحمر ساطع (R=250, G=0, B=0). (فكّر: ما نتيجة G > R + 40 وG > B + 40 في كل حالة مع انقلاب الأعداد؟)
