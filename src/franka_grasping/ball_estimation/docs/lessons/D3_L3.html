الدرس D3 · الطبقة 3: الاشتقاق

لماذا الكسب الأمثل هو K = P⁻/(P⁻ + R)؟

جواب سؤال D3 L2: الخطوة 3 من الجدول:

Predict: x̂⁻ = 0.5346 + 0.0167 = 0.5513, P⁻ = 1.03×10⁻⁵ + 4×10⁻⁶ = 1.43×10⁻⁵
z = 0.5560, y = 0.5560 − 0.5513 = 0.0047, S = 1.43×10⁻⁵ + 2.5×10⁻⁵ = 3.93×10⁻⁵
K = 1.43×10⁻⁵ / 3.93×10⁻⁵ = 0.363
x̂ = 0.5513 + 0.363 × 0.0047 = 0.5530, P = (1 − 0.363) × 1.43×10⁻⁵ = 9.08×10⁻⁶

1. صياغة المسألة

لدينا بعد خطوة التنبؤ:

  • x̂⁻: تنبؤ الموقع (معروف)
  • z: قياس الكاميرا (معروف)
  • نريد دمج التنبؤ والقياس بصيغة: x̂ = x̂⁻ + K(z − x̂⁻)
  • السؤال: أي قيمة K تعطي أفضل تقدير؟

معيار "الأفضل": نريد تقليل التباين (عدم اليقين) للخطأ بعد التصحيح. أي نقلل P = Var(x − x̂).

2. صيغة الخطأ

بعد التصحيح:

x̂ = x̂⁻ + K(z − x̂⁻) = (1 − K)x̂⁻ + Kz

الخطأ الحقيقي (الفرق بين الموقع الحقيقي والتقدير):

e = x − x̂ = x − [(1 − K)x̂⁻ + Kz]
= x − (1 − K)x̂⁻ − Kz
= (1 − K)(x − x̂⁻) − K(z − x)

لكن z = x + n حيث n ~ N(0, R) (خطأ القياس):

e = (1 − K)(x − x̂⁻) − Kn

3. تباين الخطأ

نفترض أن (x − x̂⁻) وn مستقلان:

Var(e) = Var[(1 − K)(x − x̂⁻)] + Var(Kn)
= (1 − K)² P⁻ + K² R

وهذه هي دالة K التي نريد تقليلها.

4. التقليل (Optimization)

نشتق بالنسبة إلى K ونساوي بالصفر:

d/dK [Var(e)] = 0
d/dK [(1 − K)² P⁻ + K² R] = 0
−2(1 − K)P⁻ + 2KR = 0
(1 − K)P⁻ = KR

نفك الأقواس:

P⁻ − KP⁻ = KR
P⁻ = K(P⁻ + R)
K = P⁻ / (P⁻ + R)

هذا هو الكسب الأمثل! لاحظ أنه بالفعل S = P⁻ + R من الدرس السابق، فالصيغة تصير K = P⁻ / S.

5. الحدس الهندسي

الكسب الأمثل هو نسبة (وزن) تعتمد على موثوقية كل مصدر:

  • P⁻ = عدم اليقين في التنبؤ (كبير ⟹ تنبؤ سيء)
  • R = عدم اليقين في القياس (كبير ⟹ قياس سيء)
  • K = P⁻ / (P⁻ + R) = نسبة عدم يقين التنبؤ من إجمالي عدم اليقين

فإذا كان التنبؤ سيء جداً (P⁻ ≫ R)، فـ K → 1 (نتبع القياس بقوة).
وإذا كان القياس سيء جداً (R ≫ P⁻)، فـ K → 0 (نبقى مع التنبؤ).

في مثالنا: K = 1.43×10⁻⁵ / (1.43×10⁻⁵ + 2.5×10⁻⁵) = 0.363 يعني التنبؤ أفضل من القياس قليلاً، فنعتمد عليه 63% وعلى القياس 37%.

6. التباين النهائي

بعد التصحيح بالـ K الأمثل:

P = (1 − K)² P⁻ + K² R

يمكن تبسيطها باستخدام K = P⁻ / (P⁻ + R):

P = (1 − K)P⁻ = [1 − P⁻/(P⁻ + R)]P⁻ = [R/(P⁻ + R)]P⁻
= P⁻R / (P⁻ + R)

هذا في الواقع ما نحسبه في الخطوة (كما رأيت في الدرس السابق: P = (1 − K)P⁻).

سؤال للتأكد

باستخدام الصيغة K = P⁻/(P⁻ + R) والتباين الحقيقي P = P⁻R/(P⁻ + R):

  1. عندما R → 0 (قياس مثالي)، ما هما K وP؟
  2. عندما P⁻ → 0 (تنبؤ مثالي)، ما هما؟
  3. عندما P⁻ = R (متساويان)، كم تكون نسبة K؟
