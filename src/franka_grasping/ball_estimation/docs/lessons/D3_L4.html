الدرس D3 · الطبقة 4: حيث يعيش الكود

مرشّح Kalman في البرنامج

جواب سؤال D3 L3: عندما R → 0 (قياس مثالي): K → 1 وP → 0 (نتبع القياس كلياً). عندما P⁻ → 0 (تنبؤ مثالي): K → 0 وP → 0 (نبقى مع التنبؤ). عندما P⁻ = R: K = 0.5 (نزن التنبؤ والقياس بالتساوي).

1. الملف

معادلات Kalman موجودة في estimators/filters.py. الفئة EKF19 تطبقها بشكل كامل (مع الاحتكاك والجدران والمزيد). النسخة البسيطة بدون احتكاك تُسمى cvkf (constant-velocity Kalman filter):

cvkf = EKF19(c=0.0, E=0.0, L=1e9, policy="none")

حيث c=0 معناه لا احتكاك (ثابت سرعة)، وpolicy="none" معناه لا "gate" ولا إعادة تعيين عند الأخطاء.

2. الأوزان: R وP0

في __init__:

self.R = sigma ** 2                    # خطأ القياس (الكاميرا)
self.P0 = np.diag([sigma ** 2, sigma ** 2, sigma_v0 ** 2, sigma_v0 ** 2])

R = تباين خطأ القياس (واحد للموقع، لأن القياس 2D xy). القيمة الافتراضية sigma = 0.005 m (5 ملم)، إذاً R = 2.5×10⁻⁵ (كما في مثال D3 L2).

P0 = التباين الأولي (4×4 مصفوفة قطرية): sigma² لـ x وy (الموقع)، وsigma_v0² لـ vx وvy (السرعة). القيمة الافتراضية sigma_v0 = 3.0 m/s (عدم يقين كبير في السرعة الأولى).

3. التنبؤ (Predict)

دالة _predict(dt) تغيّر الحالة والتباين عبر النموذج الديناميكي:

F = np.eye(4); F[0, 2] = F[1, 3] = h   # مصفوفة الانتقال: x += vx*dt
P = F @ P @ F.T + Q                      # التباين بعد النموذج + ضجيج النموذج

F = مصفوفة الانتقال (4×4): أعلى يسار هويّة (السرعة ثابتة)، أعلى يمين dt (الموقع يتغير). Q = ضجيج النموذج (q=0.5 افتراضي).

4. التصحيح (Correct)

في update() بعد التنبؤ:

y = z - self.s[:2]                     # التنبية (الفرق بين القياس والتنبؤ)
S = self.P[:2, :2] + self.R * np.eye(2)  # تباين التنبية
K = self.P[:, :2] @ np.linalg.inv(S)   # الكسب (P⁻ / S)
self.s = self.s + K @ y                 # تحديث الحالة
self.P = (np.eye(4) - K @ np.eye(4)[:2]) @ self.P  # تحديث التباين

لاحظ: K مصفوفة (4×2) لأن الحالة 4D (موقع + سرعة) والقياس 2D (موقع فقط).

5. المقارنة مع المعادلات

D3 L2 (1D)الكود (4D)
x̂⁻ = x̂ + uself.s = F @ self.s (propagate)
P⁻ = P + QP = F @ P @ F.T + Q
S = P⁻ + RS = self.P[:2, :2] + self.R * I
K = P⁻ / SK = self.P[:, :2] @ inv(S)
x̂ = x̂⁻ + K*yself.s = self.s + K @ y
P = (1 − K)*P⁻P = (I − K @ H) @ P

الصيغ متطابقة! الفرق الوحيد: D3 L2 متغير واحد (موقع)، الكود 4 متغيرات (موقع + سرعة). الكود يستخدم H = [[1,0,0,0],[0,1,0,0]] (نقيس الموقع فقط).

سؤال للتأكد

في الكود، self.P مصفوفة 4×4 (موقع + سرعة)، لكن self.R عدد واحد (مقياس). لماذا تصير S = self.P[:2, :2] + self.R * np.eye(2)؟ (ما الذي تقيسه كل عبارة؟)
