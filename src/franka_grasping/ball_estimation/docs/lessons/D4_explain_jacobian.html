شرح إضافي · اشتقاق الـ Jacobian من دالة الاحتكاك

كيف نحسب F = ∂f/∂s من f(s)؟

1. الدالة غير الخطية f(s)

الحالة الكاملة:

s = [x, y, vx, vy]ᵀ

الدالة التي تنبئ بالحالة الجديدة (مع احتكاك c = 0.85):

f(s) = [
  x + vx·Δt,
  y + vy·Δt,
  vx·(1 − c·Δt),
  vy·(1 − c·Δt)
]

أو مكتوبة بشكل واضح:

f₁(s) = x + vx·Δt
f₂(s) = y + vy·Δt
f₃(s) = vx·(1 − c·Δt)
f₄(s) = vy·(1 − c·Δt)

2. تعريف الـ Jacobian

الـ Jacobian هي مصفوفة المشتقات الجزئية. لدالة f: R⁴ → R⁴، الـ Jacobian (4×4) هي:

F = ∂f/∂s =

[∂f₁/∂x ∂f₁/∂y ∂f₁/∂vx ∂f₁/∂vy]
[∂f₂/∂x ∂f₂/∂y ∂f₂/∂vx ∂f₂/∂vy]
[∂f₃/∂x ∂f₃/∂y ∂f₃/∂vx ∂f₃/∂vy]
[∂f₄/∂x ∂f₄/∂y ∂f₄/∂vx ∂f₄/∂vy]

كل عنصر F[i,j] = ∂fᵢ/∂sⱼ = كم تتغير الدالة i عندما نغيّر المتغير j بمقدار صغير.

3. حساب كل عنصر

الصف الأول: المشتقات من f₁ = x + vx·Δt

∂f₁/∂x = ∂(x + vx·Δt)/∂x = 1
∂f₁/∂y = ∂(x + vx·Δt)/∂y = 0 (لا يوجد y في f₁)
∂f₁/∂vx = ∂(x + vx·Δt)/∂vx = Δt
∂f₁/∂vy = ∂(x + vx·Δt)/∂vy = 0 (لا يوجد vy في f₁)

الصف الثاني: المشتقات من f₂ = y + vy·Δt

∂f₂/∂x = ∂(y + vy·Δt)/∂x = 0
∂f₂/∂y = ∂(y + vy·Δt)/∂y = 1
∂f₂/∂vx = ∂(y + vy·Δt)/∂vx = 0
∂f₂/∂vy = ∂(y + vy·Δt)/∂vy = Δt

الصف الثالث: المشتقات من f₃ = vx·(1 − c·Δt)

∂f₃/∂x = ∂[vx·(1 − c·Δt)]/∂x = 0 (لا يوجد x)
∂f₃/∂y = ∂[vx·(1 − c·Δt)]/∂y = 0 (لا يوجد y)
∂f₃/∂vx = ∂[vx·(1 − c·Δt)]/∂vx = 1 − c·Δt (المشتقة من vx بالنسبة لـ vx)
∂f₃/∂vy = ∂[vx·(1 − c·Δt)]/∂vy = 0 (لا يوجد vy)

الصف الرابع: المشتقات من f₄ = vy·(1 − c·Δt)

∂f₄/∂x = 0
∂f₄/∂y = 0
∂f₄/∂vx = 0
∂f₄/∂vy = 1 − c·Δt

4. مصفوفة الـ Jacobian الكاملة

بجمع كل العناصر:

F =
[1, 0, Δt, 0]
[0, 1, 0, Δt]
[0, 0, 1 − c·Δt, 0]
[0, 0, 0, 1 − c·Δt]

هذا هو الـ Jacobian!

5. المقارنة مع النموذج الخطي

النموذج الخطي (D4 L2: بدون احتكاك):

F_linear =
[1, 0, Δt, 0]
[0, 1, 0, Δt]
[0, 0, 1, 0]
[0, 0, 0, 1]

النموذج غير الخطي (مع احتكاك):

F_ekf =
[1, 0, Δt, 0]
[0, 1, 0, Δt]
[0, 0, 1 − c·Δt, 0]
[0, 0, 0, 1 − c·Δt]

الفرق الوحيد: الصفان الثالث والرابع من القطر الرئيسي:

  • F_linear: قيمة 1 (السرعة ثابتة)
  • F_ekf: قيمة 1 − c·Δt ≈ 0.915 (السرعة تنقص)

6. الحدس

الـ Jacobian F[i,j] يخبرك: كم يتغير الخرج i عندما نزيد الدخل j قليلاً؟

  • ∂f₁/∂vx = Δt: إذا زدنا vx بـ 0.01 m/s، الموقع x يزيد بـ 0.01 × Δt—يعني الموقع يعتمد على السرعة بمعامل Δt.
  • ∂f₃/∂vx = 1 − c·Δt: إذا زدنا vx بـ 1 m/s، السرعة الجديدة vx_new تزيد بـ 1 − c·Δt—يعني السرعة الجديدة أصغر من القديمة (بسبب الاحتكاك).

7. مثال بأرقام

c = 0.85, Δt = 0.1:

1 − c·Δt = 1 − 0.85 × 0.1 = 1 − 0.085 = 0.915

إذاً إذا كانت vx = 1 m/s:

vx_new = 1 × 0.915 = 0.915 m/s

السرعة انخفضت من 1 إلى 0.915 (نسبة 91.5%).

8. الخطوة التالية في EKF

بعد حساب الـ Jacobian F، نستخدمه في خطوة التنبؤ للتباين فقط:

P⁻ = F·P·Fᵀ + Q

لكن الموقع نحسبه من الدالة الأصلية f(s) (غير الخطية):

s⁻ = f(s)

هذا هو الفرق الرئيسي بين Kalman والـ EKF!
