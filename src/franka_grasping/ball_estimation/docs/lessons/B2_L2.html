الدرس B2 · الطبقة 2: التعريفات الدقيقة

مصفوفة العمق، وقناع اللون، والمركز

جواب السؤال السابق: صورة اللون تقول أين الكرة في الصورة (أي البكسلات خضراء)، وصورة العمق تقول كم تبعد. في عالمنا يمكن لأيٍّ منهما أن يجد الكرة، فقمة الكرة (2.94) تختلف عن الأرض (3.0) بـ 6 سم، لكن اللون أبسط وأوضح، ولا يشتبه بين الكرة والجدران (2.90). وبالعموم اللون يخبر «أي جسم»، والعمق يخبر «أين في الفراغ».

1. الصور كمصفوفات

الصورة مصفوفة. نرمز لبكسل بالعمود u (من 0 إلى 639) والصف v (من 0 إلى 479)، وفي الكود نكتب array[v, u] (الصف أولاً):

  • صورة اللون I[v, u, c]: ثلاثة أعداد صحيحة بين 0 و255 لكل بكسل: c = R, G, B.
  • صورة العمق D[v, u]: عدد حقيقي واحد (float32) بالمتر.

مركز البكسل (u, v) هو النقطة (u, v) نفسها (أي البكسل يغطي u ± 0.5). ولذلك مركز الصورة (319.5, 239.5) (بين البكسلات الوسطى).

2. قناع اللون (color mask)

القناع مصفوفة M[v, u] قيمتها صح أو خطأ: هل هذا البكسل «أخضر»؟ تعريفنا:

M = ( G > R + 40 ) AND ( G > B + 40 )

أي: الأخضر أكبر من الأحمر بأكثر من 40 و أكبر من الأزرق بأكثر من 40. أمثلة:

  • ball (0, 200, 0): G−R = 200, G−B = 200 → mask = True
  • floor (150, 150, 150): G−R = 0 → False
  • edge pixel mixed with floor (60, 100, 60): G−R = 40, not > 40 → False

إذن بكسلات الحافة الممزوجة تُرفض، ويبقى القلب الأخضر الواضح. هذا اختيار تصميمي (العتبة 40 اخترتها أنا)، وهو يعمل جيداً هنا: وجدنا الكرة في كل الإطارات (صفر إطار ضائع).

3. المركز (centroid)

مركز البكسلات التي قيمتها True هو متوسط إحداثياتها:

uc = (1/N) ∑ ui,    vc = (1/N) ∑ vi

مثال صغير: بكسلات القناع (10,5), (11,5), (10,6), (11,6), (12,6): uc = (10+11+10+11+12)/5 = 10.8 وvc = (5+5+6+6+6)/5 = 5.6. لاحظ أن المركز عدد كسري، أي نحصل على دقة أدق من البكسل (sub-pixel) لأن المتوسط يجمع عدة بكسلات. وهذا ما يفسّر خطأ الكاميرا المثالية 1.7 مم رغم أن البكسل 7.2 مم.

في الكود نشترط N ≥ 3 بكسلات على الأقل (min_pixels) وإلا نعتبر أن الكرة غير مرئية.

4. قراءة العمق

نقرأ العمق عند أقرب بكسل للمركز: z = D[ round(vc), round(uc) ]. في مثالنا: D[198, 390] (تقريب 197.5 و389.5) فخرج 2.9408 m.

def detect(self, rgb, min_pixels=3):
    g = (rgb[..., 1] > rgb[..., 0] + 40) & (rgb[..., 1] > rgb[..., 2] + 40)   # the mask M
    if g.sum() < min_pixels:
        return None
    v, u = np.nonzero(g)                  # rows and columns of the True pixels
    return u.mean(), v.mean()             # the centroid (u_c, v_c)
